# Fonts

Self-hosted Poppins (UI) and Aleo (display) WOFF2 subsets used by
`src/web/styles/tailwind.css`. Both use the SIL Open Font License 1.1; the
licence files are committed here and must remain with redistributed font files.

The checked-in Latin and Latin Extended subsets cover English and French.
Only add a weight, style, or subset when the UI actually uses it.

Upstream sources: `google/fonts/ofl/poppins` and `google/fonts/ofl/aleo`.
