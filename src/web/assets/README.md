# Assets

Committed, self-hosted assets for both static routes. Pages must not fetch fonts,
logos, or scripts from third parties.

- `fonts/`: Poppins and Aleo WOFF2 subsets with SIL OFL licence text.
- `hpac-logo.png`: current 260×125 HPAC source image. Replace it when HPAC
  supplies a high-resolution light-surface asset.

Keep provenance and licence files beside any replacement asset.
